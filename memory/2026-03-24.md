## GoHardVPN Build Fix

- **Problem:** App failed to build/package — `JAVA_HOME` was not set. Gradle couldn't find Java.
- **Solution:** Set `JAVA_HOME=C:\Program Files\Android\Android Studio\jbr` (Android Studio's JetBrains Runtime)
- **Result:** `assembleDebug` succeeded, APK generated at `GoHardVPN/app/build/outputs/apk/debug/app-debug.apk` (~47MB)
- **Installed** on device `06820311C1151457` via adb, launched successfully (PID 30018)
- **Note:** User should set JAVA_HOME permanently in system environment variables to avoid this again
