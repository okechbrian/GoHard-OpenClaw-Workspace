## Fix: Disabled Selenium in power‑monitor config

- **Issue:** `use_selenium` was set to `true`, which caused the script to look for a Chrome binary. The binary lookup failed on the host, leading to fetch errors and preventing the script from retrieving UEDCL news/outage updates.
- **Correction:** Updated `skills/power-monitor/scripts/power-monitor.config.json` to include `"use_selenium": false`. This removes the Chrome dependency and makes the script use the `r.jina.ai` fallback fetcher for all URLs.
- **Result:** The script now runs a dry‑run successfully without Chrome errors. A test `getUpdates` call to the Telegram channel shows no new messages since the last update (msg_id=68), confirming the channel is current.
- **Next steps:** If fresh UEDCL news is required, run `python power_monitor.py --dry-run` (or the full script) to fetch the latest articles and outage alerts. The bot will then post any new bulletins to the Telegram channel.
